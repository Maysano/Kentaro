# Portfolio workflows

Identify environment and portfolio scope before retrieval.
Use `kentaro portfolio brief` for the packaged synthetic demo. It requires no
repository fixture or configuration file. Use `kentaro portfolio brief --source
maysano` only after the user has explicitly configured the read-only source with
`kentaro configure maysano`.
Cite IDs, versions, record timestamps and retrieval time; identify fixture data as synthetic.
Distinguish facts, calculations, inferences and recommendations. Never invent provenance.
Save generated output under `.kentaro/workspace/`. Never call platform write APIs or
imply approval.
The demo is not a live platform connection or a model-assisted analysis.
