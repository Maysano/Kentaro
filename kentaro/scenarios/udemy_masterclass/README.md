# Udemy Masterclass scenario package

This package is the first application of Kentaro's reusable local `DesignPortfolio` engine. It
contains only fictional banking material: the Customer Risk Intelligence starting case, ODPS
fixtures, course checkpoints, and facilitator answer key. It adds no scenario-specific domain
logic to `kentaro.design`.

Use `kentaro masterclass` for backward-compatible course commands, or explicitly select it with
`kentaro design init --scenario udemy-masterclass --output <workspace path>`.
